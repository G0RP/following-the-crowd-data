# following-the-crowd-data
Contact information of Main Author: Alison Gladwell; alij.gladwell@gmail.com
Data collected during the summers of 2022 and 2023 from Northeastern Vancouver Island, assessing boater behaviour and compliance around Humpback and Killer Whales. Associated paper is in the submission process, titled "Following the Crowd: Social Influence on Vessel Behaviours near whales in Northeast Vancouver Island". Detailed methods of data collection and analysis are included in this paper, please reach out to main author if any questions arise.
